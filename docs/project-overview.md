# Project Overview

Local Farmer Market connects community farmers directly with consumers. Farmers will be able to list produce, while buyers can discover products and manage orders.

## Current foundation

- Frontend: React, TypeScript, Vite, React Router, Tailwind CSS v4, Zustand, TanStack Query and Axios.
- Backend: Express and TypeScript with placeholder API namespaces and a health endpoint.
- Future integrations: Supabase Auth/Storage and PostgreSQL through Prisma. No credentials, live connection, data models or migrations are configured yet.
